# Radio Every Day 设计风格优化文档

> 本文档沉淀了项目首轮 UI 优化的全部设计决策与实现细节，作为后续迭代的风格基线。

---

## 一、整体设计理念

### 1.1 双态布局

应用存在两种核心视图状态，通过手势无缝切换：

| 状态 | 视觉特征 | 交互 |
|---|---|---|
| **展开态（Expanded）** | 深色 Header + 声波律动 → 白色圆角卡片（标题/进度/讲稿）→ 底栏 MiniPlayer | 在白色卡片区域**下滑**收起 |
| **收起态（Collapsed）** | 精简 Header → 独立律动 + 标题 + 播放按钮 → 底部折叠白色卡片 | 在底部卡片**上滑**展开 |

### 1.2 视觉层次

```
┌──────────────────────────────┐
│  深色区域（#0b0c10）          │  ← Hero 背景
│  · 白色亮点纹理（低透明度）   │
│  · 声波律动条（底部对齐）     │
├──────── 圆角卡片顶部 ─────────┤  ← border-radius: 42px
│  白色区域（#ffffff）          │  ← PlayerCard
│  · 标题 / 元信息 / 进度条     │
│  · 逐字高亮讲稿面板           │
│  · MiniPlayer 底栏            │
└──────────────────────────────┘
```

## 三、组件设计规范

### 3.1 HeroSection（顶部深色区域）

**展开态：**
- 高度：`305px`
- 内边距：`28px 28px 0`
- 包含：品牌区（头像 38px + 品牌名 30px/5px字间距）+ 状态指示 + 声波律动
- 律动条参数：`align-items: flex-end`, `gap: 8px`, `max-width: 6px`, `min-width: 4px`, `padding: 0 28px`, `transform-origin: bottom`

**收起态（compact）：**
- 高度：`auto`（由内容撑开）
- 内边距：`18px 28px 16px`
- 品牌区缩小：头像 30px，品牌名 22px/4px字间距
- 隐藏状态指示和声波律动（律动移至 CompactPlayer 内独立展示）
- 所有尺寸变化通过 `transition: 0.5s cubic-bezier(0.4,0,0.2,1)` 平滑过渡

**亮点纹理：**
```css
.hero::before {
  opacity: 0.28;
  background-image: radial-gradient(rgba(255,255,255,0.45) 1px, transparent 1px);
  background-size: 18px 18px;
  mask-image: linear-gradient(to bottom, black 60%, transparent 100%);
}
```
- 亮点覆盖上方 60% 区域，下方自然淡出
- 透明度控制在可见但不抢注意力的范围

### 3.2 PlayerCard（白色圆角卡片）

**布局：**
- `border-radius: 42px 42px 0 0`（顶部大圆角）
- `padding: 28px 26px 96px`（底部 96px 为 MiniPlayer 留空间）
- `height: 100%; display: flex; flex-direction: column; overflow: hidden`
- 圆角卡片向上延伸 40px（`card-wrap: top: -40px`）覆盖律动区域底部

**一屏适配策略：**
- 标题字号：`44px`（相比初始 52px 压缩）
- 元信息字号：`16px`（相比初始 18px 压缩）
- 各区域间距收紧（标题 margin `4px 0 6px`，meta margin-bottom `22px`，进度条 margin-bottom `20px`）
- TranscriptPanel 使用 `flex: 1; min-height: 0` 自适应填充剩余空间

### 3.3 TranscriptPanel（逐字高亮讲稿）

**布局：**
- `flex: 1; min-height: 0; overflow-y: auto` — 自动填充剩余空间，内容多时可滚动
- `padding: 20px 18px`，行间距 `18px`
- 正文字号 `20px`（相比初始 24px 压缩）

**逐字高亮逻辑：**
- 每条讲稿数据需包含 `time`（开始时间）和 `endTime`（结束时间）
- 当前活跃行：按时间进度比例计算高亮字符数，逐字切换 `.char-active`（`rgba(0,0,0,0.92)`）/ `.char-inactive`（`rgba(0,0,0,0.16)`）
- 已播行（past）：整行全亮
- 未播行：整行淡色
- 过渡动画：`transition: color 0.15s ease`

**关键词高亮：**
```css
.highlight {
  background: linear-gradient(180deg, transparent 48%, rgba(117,226,189,0.62) 48%);
  border-radius: 4px;
  padding: 0 2px;
}
```

### 3.4 MiniPlayer（展开态底栏）

- `position: absolute; bottom: 0; height: 96px`
- 半透明毛玻璃：`background: rgba(255,255,255,0.88); backdrop-filter: blur(18px)`
- 布局：`grid-template-columns: 52px 1fr 52px`（时间 + 波形 + 按钮）

### 3.5 CompactPlayer（收起态紧凑面板）

**整体结构（从上到下）：**

```
┌──────────────────────────────┐
│  独立声波律动区域（120px）     │
│  gap:8px, max-width:6px      │
│  transform-origin: bottom    │
├──────────────────────────────┤
│         间距 36px             │
├──────────────────────────────┤
│  标题（34px, 最多2行省略）    │
│  作者（14px, 淡色）           │
├──────────────────────────────┤
│         间距 52px             │
├──────────────────────────────┤
│     ● 播放按钮（64px）        │
│     白底黑icon + 涟漪动画     │
├──────────────────────────────┤
│  底部折叠白色卡片（72px）     │
│  圆角顶部 + 阴影 + 拖拽条     │
│  "上滑展开讲稿" 提示文字      │
└──────────────────────────────┘
```

**亮点纹理：**
```css
.compact-content-dots {
  opacity: 0.2;
  background-image: radial-gradient(rgba(255,255,255,0.4) 1px, transparent 1px);
  background-size: 16px 16px;
}
```

**标题规范：**
- `font-size: 34px; font-weight: 700; line-height: 1.2; letter-spacing: -1px`
- 两行省略：`-webkit-line-clamp: 2; -webkit-box-orient: vertical; overflow: hidden`

**播放按钮 + 涟漪动画：**
- 按钮：`64px` 圆形，`background: white; color: #111; box-shadow: 0 4px 20px rgba(0,0,0,0.15)`
- 涟漪：两层 `div.ripple`，`animation: rippleExpand 2.4s ease-out infinite`，第二层延迟 `1.2s`
- 仅在 `isPlaying` 时激活涟漪动画
- 涟漪效果：`scale(1)→scale(2.8)`，`opacity: 0.45→0`

**折叠卡片：**
- `background: white; border-radius: 28px 28px 0 0; height: 72px`
- `box-shadow: 0 -8px 32px rgba(0,0,0,0.12)` — 立体感上投阴影
- 拖拽条：`width: 36px; height: 4px; border-radius: 2px; background: #d0d0d0`
- 提示文字：`font-size: 11px; color: #aaa`

## 四、动画规范

### 4.1 状态切换动画

**收起（展开态 → 收起态）：**
1. PlayerCard：`translateY(0) → translateY(60px)` + `opacity: 1 → 0`，时长 `0.45s`
2. HeroSection：高度/padding/字号平滑过渡，时长 `0.5s`
3. CompactPlayer：延迟 `0.12s` 后，`translateY(24px) → translateY(0)` + `opacity: 0 → 1`，时长 `0.5s`

**展开（收起态 → 展开态）：**
1. CompactPlayer：`translateY(0) → translateY(16px)` + `opacity: 1 → 0`，时长 `0.35s`
2. HeroSection：高度/padding/字号平滑过渡，时长 `0.5s`
3. PlayerCard：延迟 `0.12s` 后，`translateY(60px) → translateY(0)` + `opacity: 0 → 1`，时长 `0.5s`

**缓动函数：** `cubic-bezier(0.4, 0, 0.2, 1)`（Material Design 标准缓出）

### 4.2 声波律动动画

```css
@keyframes wavePulse {
  0%, 100% { transform: scaleY(0.72); opacity: 0.62; }
  50%      { transform: scaleY(1);    opacity: 1; }
}
```
- 周期：`1.6s ease-in-out infinite`
- 每条延迟：`calc(var(--i) * -0.06s)` 产生波浪效果
- **必须** `transform-origin: bottom` 保证底部对齐

### 4.3 涟漪动画

```css
@keyframes rippleExpand {
  0%   { transform: scale(1);   opacity: 0.45; }
  100% { transform: scale(2.8); opacity: 0; }
}
```
- 周期：`2.4s ease-out infinite`
- 双层涟漪间隔 `1.2s`

### 4.4 HeroSection 尺寸过渡

所有受 `compact` 模式影响的属性都应加 transition：
```css
.hero        { transition: height 0.5s, padding 0.5s; }
.avatar      { transition: width 0.5s, height 0.5s; }
.brand-name  { transition: font-size 0.5s, letter-spacing 0.5s; }
.time        { transition: font-size 0.5s; }
```

## 五、播放/暂停图标规范

### 5.1 统一原则

播放和暂停图标必须在视觉上**等大、等重、风格一致**。

### 5.2 播放图标（SVG 圆角三角形）

```html
<svg width="14" height="16" viewBox="0 0 14 16" fill="currentColor">
  <path d="M2 2.1L12 8L2 13.9V2.1Z"
    stroke="currentColor" stroke-width="1.8"
    stroke-linejoin="round" stroke-linecap="round"/>
</svg>
```

- `stroke-linejoin: round` + `stroke-linecap: round` 实现三角形的圆角效果
- viewBox 与暂停图标视觉等大

### 5.3 暂停图标（CSS 双竖条）

```css
.pause-icon {
  width: 14px;
  height: 16px;
  display: flex;
  gap: 4px;
}
.pause-icon::before,
.pause-icon::after {
  content: "";
  width: 4px;
  border-radius: 8px;
  background: currentColor;
}
```

### 5.4 使用场景

| 场景 | 按钮样式 | 图标色 |
|---|---|---|
| PlayerCard 进度条旁 | 黑底圆 `38px` | 白色 |
| MiniPlayer | 黑底圆 `38px` | 白色 |
| CompactPlayer 中央 | 白底圆 `64px` + 涟漪 | 黑色 |

## 七、布局关键数值

### 7.1 展开态垂直空间分配

```
100dvh
├── HeroSection: 305px (固定)
└── content-area: 剩余空间
    └── card-wrap: top=-40px → 向上覆盖律动底部 40px
        └── PlayerCard: height=100%, padding-bottom=96px
            ├── 标题区 (~70px)
            ├── 进度条 (~40px)
            ├── TranscriptPanel: flex=1, 自适应
            └── MiniPlayer: 96px (absolute bottom)
```

### 7.2 收起态垂直空间分配

```
100dvh
├── HeroSection: auto (compact模式, ~64px)
└── content-area: 剩余空间
    └── CompactPlayer: position=absolute, inset=0
        ├── compact-content: flex=1, 居中排列
        │   ├── 律动区域: 120px
        │   ├── 标题+作者: ~80px
        │   └── 播放按钮: 64px
        └── collapsed-card: 72px
```

## 九、已知的可优化方向

1. **手势跟手**：当前手势是阈值触发，可改为跟手拖拽（实时 translateY 跟随手指）
2. **讲稿自动滚动**：TranscriptPanel 当前高亮行不在视口时自动滚动到可见区域
3. **真实音频接入**：当前 `/demo.mp3` 为占位，需接入 TTS 生成结果
4. **节目列表页**：收起态底部折叠卡片可扩展为节目历史列表
5. **BottomMiniBar 复用**：全局迷你播放栏，在非播放页面的底部常驻显示
